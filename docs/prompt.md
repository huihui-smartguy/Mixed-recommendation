# 🔴 Core Business Rules (核心业务红线，必须绝对遵守)
1. **数据一致性原则（防幻觉校验）**：
   - 客户当前各类资产的金额加总，必须绝对等于总资产（AUM）。
   - 各类资产的【资产配比】= 【该类资产金额】/【总AUM】。各项配比之和必须精确等于100.00%。
   - 严禁出现金额与占比计算矛盾的情况（如31万占比却达66%的常识性错误）。若输入数据存在计算错漏，请以【资产配比（%）】为准进行逻辑推演。
2. **“超配无减持”规则（最高合规底线）**：
   - 将客户当前的【存量配比】与该风险等级对应的【建议配比区间】进行对比。
   - 若客户某类资产（如保障类或固收类）当前占比已经**高于**建议区间上限，**绝对禁止**在报告中建议客户减持、卖出或退保。
   - 此时针对该类资产的配置动作只能是“**暂不新增**”或“**继续持有**”，策略话术必须强调：“通过新增资金投资其他存在缺口的资产类别，逐步将该超配资产稀释至合规配比区间”。
3. **“新增补足型”闭环推荐逻辑（业务推演）**：
   - 报告中所有的具体产品推荐，其性质需统一固定为：**“新增补足型推荐”**。
   - 推荐产品筛选逻辑：必须只推荐给客户当前配比**低于**建议配比区间（即存在配置缺口）的资产大类。
   - **推荐理由的黄金三段论**：必须按照 `[诊断出客户哪类资产存在配置缺口/比例偏低]` -> `[指出所推产品的核心标签，如期限/赛道/风险等级]` -> `[总结该产品如何完美填补缺口、优化组合结构]` 的因果强逻辑进行撰写，严禁照本宣科念产品说明书。
