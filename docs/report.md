## 一、宏观经济与市场展望（第4-6页）

### （一）全球经济分析

#### 中东局势影响

中东局势恶化对美国宏观经济的影响是 **"双刃剑"**，但冲突持续或将弊大于利：

| 影响方向     | 分析要点                                                 |
| -------- | ---------------------------------------------------- |
| **有利方面** | 美国作为能源净出口国，能源企业从油价上涨中受益，促进国内油气行业投资和就业，改善贸易收支         |
| **不利方面** | 依赖石油作为原材料的制造、航空等行业成本上升，挤压家庭可支配收入和企业利润，尤其是中低收入群体消费受影响 |
| **政治影响** | 中东局势持续动荡或影响特朗普在美国国内的支持率，已创下二次上任后的新低                  |

#### 美联储货币政策

美联储货币政策在 **就业市场放缓** 和 **通胀上行** 之间权衡：

- **3月点阵图**显示今年仍有一次 **25个基点** 的降息预期，3月议息会议按兵不动
- 近期油价飙升对通胀带来影响，投资者已将全年降息预期 **下调至零次**，降息时间推迟到明年
- **油价成为美联储降息的重要掣肘因素**
- 考虑到美联储人选变动和中期选举影响，实际降息或大于基准预期
- **预测判断**：降息至少被推后到6月考虑，更大概率在下半年重启
- **核心观点**：不赞成美联储接下来将会加息的判断。在能源危机持续、导致美国经济陷入滞胀或衰退的情形下，美联储决议的天平会更偏向 **稳增长**，而不是再通胀

> 注：以上信息根据《财资赛道资配工作室资产配置资产分析报告》总结

### （二）国内经济分析

#### 一季度经济走势

- 一季度经济走势或实现 **十五五的稳健开局**
- 春节错位影响：生产、需求集中体现在 **1-2月** 数据中，开门红取得季节性成效
- 3月经济运行相应受到挤压

#### 二季度核心关注

| 关注点       | 分析判断                                                                            |
| --------- | ------------------------------------------------------------------------------- |
| **上游通胀**  | 国际地缘冲突推升原油价格，对国内通胀形成输入性抬升；伴随反内卷，产能过剩行业不断出清，二季度有望见到 **PPI同比转正**                  |
| **房地产市场** | 高频数据显示楼市小阳春走势符合季节性特征，需密切关注一线城市二手房价格企稳情况，对应内需或进入持稳状态（前期政策透支，接续政策力度退坡，整体内需反弹节奏偏缓） |

#### 外部环境

- **核心变量**：地缘格局变动仍是短期经济的核心变量
- **安全科技博弈**：仍是长期大方向
- **全球形势**：全球地缘波动形势加剧，输入性通胀压力大增，全球进入 **暂时性滞胀时期**
- **中美关系**：中美两国迎来总量经贸层面的缓和期，但在安全和科技板块，大国博弈或仍持续

#### 政策展望

| 政策类型     | 取向判断                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------- |
| **财政政策** | 关注财政发力节奏，预计年度财政保持 **靠前发力** 格局，以应对地缘政治不确定性                                                                         |
| **货币政策** | 保持 **配合式宽松**，流动性延续合理充裕概率较高，但总量货币政策尚未见到触发剂。二季度货币政策取向仍是 **支持性** 的，维持流动性充裕意图较为确定，资金环境有望维持 **均衡偏松**，且"收短放长"确保资金充裕但不漫灌 |

> 注：以上信息根据《财资赛道资配工作室资产配置资产分析报告》总结
